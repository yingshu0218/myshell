## 文件归属

- macos/Sources/、Support/：应用与 Darwin PTY 源码。
- macos/Tests/：自动化测试。
- macos/Resources/：图标与本地化资源。
- macos/MyShell.xcodeproj/、Package.swift、Package.resolved：工程和锁定依赖。
- macos/script/：构建、性能测量和打包入口。
- macos/docs/：决策、历史验证数据和发布说明。
- shared/：版本化 schema、加密信封、公开测试向量和样例。
- macos/.codex/environments/environment.toml：可共享的运行入口，不含凭据。

构建缓存、DerivedData、dist、运行数据库、日志、诊断 trace 和本地 IDE 状态
留在本机并被 Git 忽略。公开密码学向量中的固定密钥仅用于测试。
