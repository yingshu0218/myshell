# Web 终端与同步服务实施计划

## 技术基线

- 后端：Go 单进程
- 前端：原生 HTML、CSS、JavaScript
- 部署：单 Docker 容器
- SSH：容器内系统 OpenSSH 客户端
- 持久化：版本化文件和原子替换
- 日常同步：自建 HTTPS API
- 后备：可选 GitHub/Gitea 加密备份
- 依赖：默认不引入；所有第三方包必须先获批准

## 0. 服务骨架

建立 Go module、`cmd/server/`、`internal/`、`web/`、测试目录和 Docker 构建
结构。实现配置校验、优雅退出、`/health` 和结构化脱敏日志。

验收：Go 构建与测试通过，容器能够启动、响应健康检查并正常退出。

## 1. 单用户认证

实现首次管理员初始化、密码哈希、登录、退出、会话过期和失败限速。初始化成功
后关闭注册入口。实现安全 Cookie 与 CSRF 防护。

验收：认证测试覆盖成功、失败、锁定、过期、并发和服务重启。

## 2. 管理命令

同一可执行文件提供 `serve`、`reset-password` 和 `show-account` 子命令。
密码重置采用交互输入并使全部会话失效。

验收：密码不出现在参数、输出、日志或进程列表中。

## 3. PTY 与终端传输

建立终端会话管理器，支持 Linux Shell、系统 SSH、窗口尺寸变化、输入输出流、
退出码、超时和强制关闭。每个会话设置缓冲及资源上限。

验收：关闭浏览器、断网、SSH 退出及容器停止均不会遗留进程。

## 4. 浏览器终端界面

实现登录页、连接侧边栏、多标签终端、连接状态、尺寸适配和快捷操作。后台
标签页降低渲染频率；不引入大型 UI 框架。

验收：键盘、粘贴、Unicode、颜色、全屏程序和断线提示可用。

## 5. 加密保险库

定义版本化连接模型与加密封装，使用 Docker Secret 提供恢复密钥。以临时文件
写入并原子替换正式文件，保留有限数量的本地恢复版本。

验收：磁盘、网络、日志及崩溃输出中不存在明文凭据。

## 6. 同步 API

实现获取保险库、条件更新、冲突响应和同步状态。为未来 macOS/Windows 客户端
固定请求、错误和版本兼容规则。

验收：并发修改不会静默覆盖，网络重试不会产生重复记录。

## 7. 在线状态检查

实现中转服务健康状态和 SSH 目标端口检查。支持单个、全部、手动及定时检查，
设置超时、并发上限和 5/15/30/60 分钟周期。

验收：检查不会发起 SSH 登录，空闲且未启用定时时不产生轮询。

## 8. Git 加密备份

实现 GitHub/Gitea 私有仓库配置、手动备份、每日/每周调度、备份列表及确认
恢复。Git Token 使用专用 Secret；仓库只接收加密快照。

验收：备份失败不影响同步；恢复不会未经确认覆盖当前保险库。

## 9. Docker 与安全加固

使用多阶段构建、非 root 运行、只读文件系统和最小权限。明确数据卷、Secrets、
HTTPS 反向代理及升级步骤。

验收：镜像不含源码、构建缓存、凭据或调试工具；重启和升级不丢数据。

## 10. 性能与发布

测量生产二进制和镜像大小、启动时间、空闲 CPU、基础内存、每终端会话增量、
大流量输出及 24 小时稳定性。

通过 `docs/DEVELOPMENT.md` 的全部完成标准后发布第一版，并开始规划 macOS
客户端。

## 每阶段门禁

1. 相关测试、`go vet` 和生产构建通过。
2. 无敏感信息进入源码、日志、镜像或 Git。
3. 资源有界且无明显泄漏。
4. 未经批准没有第三方依赖。
5. 文档与实际命令同步更新。
