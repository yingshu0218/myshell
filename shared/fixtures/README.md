# 跨平台同步测试数据

本目录保存 Web、macOS 和 Windows 必须共同使用的固定测试数据。它们只用于
开发和验收，不得导入真实账户。所有主机均来自保留测试地址或 `.invalid`
域名；用户名、密码和指纹均为虚构值。

## 固定数据集

- `vault-sync-v1.json`：完整的 MyShell Web 保险库输入。
- `vault-sync-v1.expected.json`：读取、过滤和同步后的预期结果。
- `VALIDATION.md`：各平台使用真实中转服务及备份服务的验收记录。

测试端必须原样读取 JSON，不能在代码中复制一份数据。每个平台至少验证：

1. 能读取 4 条记录，并只显示 3 条未删除记录。
2. UUID、UTC 时间、Unicode 名称、IPv4、IPv6 和非默认端口不发生变化。
3. 密码中的空格、引号、反斜杠和 Unicode 可以完整往返。
4. `deleted: true` 被解释为 tombstone，不能重新显示为活动连接。
5. `healthPeriod` 只接受 0、5、15、30、60。
6. 写入中转服务后，返回版本必须递增，旧版本写入必须得到 `409`。
7. 加密备份恢复后的业务数据必须与 `expectedActiveIds` 和
   `expectedPasswordById` 一致。

测试可以生成新的传输版本、nonce 和密文，因此不得比较加密文件的原始字节；
应在认证解密后比较业务字段。任何公共字段变化都必须新增数据集版本，禁止
原地改变 `v1` 的含义。
