# 代码高亮规范

## 1. 功能边界

第一版提供只读代码预览，不制作完整编辑器。用户通过以下方式打开：

- 从明确的文件查看操作打开
- 将选中的终端文本手动选择“以代码预览”
- 粘贴片段并选择语言

不得自动把全部终端输出转换成高亮 HTML。终端 ANSI 渲染与代码语法高亮必须
保持为两个隔离的渲染管线。

## 2. 第一版语言

- Shell / Bash / Zsh
- YAML
- JSON
- TOML
- Go
- Swift
- C#
- JavaScript / TypeScript
- HTML / CSS
- Dockerfile
- SQL
- Markdown

自动识别只依据可信文件扩展名、显式语言选择和少量受限启发规则。识别不确定时
使用纯文本，不能为了“看起来高亮”猜错语言。

## 3. 预览能力

- 行号
- 当前行
- 语言显示与手动切换
- 复制全部或选中内容
- 搜索
- 自动换行开关
- 水平滚动
- 字号和行高继承主题设置
- 代码与终端分屏
- 独立标签或窄屏全屏预览

第一版不实现编辑、保存远程文件、语言服务器、代码补全、Diff 或 Git 操作。

## 4. 安全边界

- 所有输入先按纯文本处理。
- 高亮结果不得允许脚本、事件属性或任意 HTML 执行。
- 不使用不受控的 `innerHTML` 注入终端或服务器返回内容。
- 单个预览默认上限 1 MiB、20,000 行，超限时拒绝或截断并明确提示。
- 搜索、高亮和语言检测必须可取消，避免大文件阻塞页面。
- 代码正文、文件内容和选中终端内容不得进入日志、活动记录或 Sync Hub。
- 外部链接默认不自动激活。

## 5. 性能策略

- PrismJS 只打包批准的语言 grammar，不加载完整语言集合。
- 使用按语言加载或构建期裁剪，避免运行时 CDN。
- 大于 200 KiB 的预览进入 Web Worker，避免阻塞终端交互。
- 行号使用虚拟化或有界 DOM；禁止每次主题切换重新解析代码。
- 主题切换只更新 CSS 变量。
- 后台代码预览降低绘制和搜索频率。

## 6. 与主题系统的关系

高亮器只输出稳定 token 类名，例如：

```text
token.comment
token.keyword
token.string
token.number
token.function
token.property
```

颜色全部来自 `THEMES.md` 的语义令牌。禁止为某种语言写死与当前主题冲突的
颜色。五个主题必须使用同一份代码片段做快照对比。

## 7. 测试要求

- 每种支持语言至少一个固定示例。
- HTML、脚本片段和事件属性不会执行。
- 1 MiB、20,000 行以及超限输入行为可预测。
- 切换五种主题不会重新解析或改变代码文本。
- Unicode、制表符、超长行和无末尾换行正确显示。
- 复制结果是原始文本，不包含行号或高亮标记。
- 窄屏预览无水平页面溢出。

PrismJS 属于候选第三方依赖；获得明确批准前不得下载或开始依赖实现。
