# MyShell Web 界面设计规范

## 1. 设计方向

MyShell Web 是工具型工作台，不是营销页面。视觉方向为“安静、精确的原生桌面
终端”：终端内容是第一视觉焦点，导航和状态信息保持紧凑，避免卡片化、玻璃、
发光、装饰渐变和无意义动画。

默认主题为“午夜石墨”，使用近黑石墨背景、冷灰边框、青色主强调色、绿色成功
和琥珀色警告。正文和代码必须保持清晰对比。UI 使用紧凑无衬线字体，终端与
代码使用等宽字体。

## 2. 主终端工作台

桌面布局由五个稳定区域组成：

```text
┌──────────────┬─────────────────────────────────────────────┐
│ 连接侧边栏   │ 标签栏 / 同步状态 / 主题                    │
│              ├───────────────────────┬─────────────────────┤
│ 分组与主机   │ 终端画布              │ 可选代码预览        │
│ 在线状态     │                       │ 行号与语法高亮      │
│              ├───────────────────────┴─────────────────────┤
│ 设置入口     │ SSH、延迟、编码、光标位置状态栏             │
└──────────────┴─────────────────────────────────────────────┘
```

### 连接侧边栏

- 桌面宽度固定在 248–272 px。
- 顶部只显示品牌和收起按钮。
- “新建连接”“检查全部”为主要操作。
- 连接按分组排列；一行包含主机图标、名称、状态点和更多菜单。
- 当前连接以左侧青色细线和轻微表面色变化表示，不能使用巨大背景卡片。
- 在线、警告、离线必须同时使用颜色和可读文本/提示，不仅依赖颜色。

### 标签栏

- 标签显示会话类型图标、标题和关闭按钮。
- 活动标签使用青色底边和更清晰文字。
- 支持本地 Shell、SSH、代码预览三种标签语义。
- 标签过多时水平滚动或出现溢出菜单，不得无限压缩文字。

### 终端画布

- 占据最大可用面积。
- 内容内边距建议 24–30 px。
- 默认字号 14 px、行高 1.5，可在设置中调整。
- 不为每行或命令添加额外装饰。
- 后台标签页降低绘制频率，但不能丢失有界输出。

### 代码预览分屏

- 用户明确触发“以代码预览”后出现。
- 默认占工作区 34–40%，支持拖动调整和关闭。
- 标题显示文件名与语言，提供“复制”“关闭预览”。
- 显示行号、当前行、水平滚动和只读状态。
- 不自动把全部终端输出解释为代码，避免错误高亮和安全问题。

### 状态栏

- 左侧：会话类型、连接状态。
- 右侧：延迟、编码、光标行列。
- 高度 34–38 px，信息紧凑，不使用装饰性徽章。

## 3. 设置页

设置导航包含：

- 常规
- 终端
- 外观
- 同步
- 安全
- 关于

“外观与代码高亮”页面包含：

1. 五套主题预览和选中状态。
2. 跟随系统开关。
3. 终端字体、字号和行高。
4. 显示行号与自动识别语言。
5. 大型实时代码预览和终端预览。
6. 同一片段的五主题对比条。
7. “恢复默认”和“保存设置”。

设置修改先进入本地草稿；保存成功后应用并按非秘密设置规则进入同步。关闭有
未保存修改的页面时必须提示。

## 4. 响应式行为

### ≥ 1180 px

- 完整侧边栏、终端和可选代码分屏。
- 设置页使用左侧导航与右侧预览。

### 768–1179 px

- 侧边栏可收起为抽屉。
- 代码预览默认占 42–48%，也可切换为独立标签。
- 工具栏隐藏次要文字但保留可访问名称。

### < 768 px

- 一次只显示一个主要区域。
- 连接列表使用全高抽屉。
- 代码预览使用独立全屏视图。
- 不强行在窄屏并排终端与代码。
- 保留外接键盘操作，但明确移动浏览器不是第一版主要使用环境。

## 5. 交互和键盘

- `⌘/Ctrl + K`：连接/命令快速查找
- `⌘/Ctrl + T`：新建终端
- `⌘/Ctrl + W`：关闭当前标签
- `⌘/Ctrl + Shift + P`：命令面板（后续阶段）
- `⌘/Ctrl + ,`：设置
- `⌘/Ctrl + Shift + C`：复制终端选择
- `⌘/Ctrl + Shift + V`：粘贴

所有按钮、菜单、标签、分隔条和表单控件必须支持键盘操作、清晰焦点环和语义化
名称。动画遵守 `prefers-reduced-motion`。

## 6. 组件边界

```text
AppShell
├── ConnectionSidebar
├── SessionTabBar
├── Workspace
│   ├── TerminalPane
│   ├── SplitHandle
│   └── CodePreviewPane
├── StatusBar
├── ThemePopover
└── SettingsView
    ├── SettingsNavigation
    ├── ThemeGallery
    ├── TerminalTypographyForm
    └── HighlightPreview
```

相同类型元素必须复用同一组件和主题令牌。`AppShell` 只负责组合，不承载终端、
同步或加密业务逻辑。

## 7. 视觉验收

实现完成前必须逐项对比概念稿：

- 信息架构和区域比例
- 可见文案与控件顺序
- 主题色、表面色和边框
- UI 与等宽字体层级
- 标签、连接行、设置控件和状态栏密度
- 代码高亮与终端内容可读性
- 侧边栏、代码分屏和主题弹层状态
- 桌面、平板和窄屏布局

浏览器截图必须与概念稿使用相近视口进行对比，并记录差异、修复和无法避免的
偏差。不能以“功能可用”代替视觉验收。
